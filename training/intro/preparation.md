# 一周预备内容

预计总投入 60–90 分钟。本阶段不评分、不收集结果，也不要求学习 Python 或 Rust 语法。已经掌握的内容可以跳过。

## A. 终端、文件与路径

建议用时约 20 分钟。

1. 观看资源表中指定的终端、文件与路径入门材料。
2. 打开系统终端，知道它与图形化文件管理器不是同一个工具。
3. 使用普通文本编辑器创建 `hello.txt`，写入任意一句话。
4. 在文件管理器中确认文件名称、扩展名和保存位置。
5. 尝试在终端中定位 `hello.txt` 所在目录。

自检：

- 文件名、文件路径和当前目录分别是什么？
- 文本编辑器、文件管理器和终端分别解决什么问题？
- 为什么“文件明明存在”仍可能出现找不到文件？

## B. Git 与 GitHub

建议用时约 25 分钟。

1. 创建或确认自己拥有可登录的 GitHub 账号。
2. 从 Git 官方入口安装适合当前系统的 Git。
3. 确认 Git 可以启动并显示版本信息。
4. 观看资源表中指定的 Git 与 GitHub 概念材料。

本阶段不要求配置 SSH key、创建仓库或完成 push。

自检：

- Git 与 GitHub 是同一个东西吗？
- Git 主要保存什么？
- 为什么安装 Git 不等于拥有 GitHub 账号？

## C. 程序与项目预览

建议用时约 15 分钟，只观看材料。

需要形成以下初步认识：

- 源代码通常是纯文本。
- 源代码需要解释器或编译器才能运行。
- 一个项目通常还包含依赖、配置、测试和文档。
- 项目在一台电脑上能运行，不代表换一台电脑仍能直接运行。

不要求记忆术语定义；基础课会用完整案例重新讲解。

## D. Windows WSL2

建议用时约 20–30 分钟，仅适用于 Windows 候选人。

1. 阅读微软官方的 WSL 和 WSL2 介绍。
2. 确认自己的系统是否具备相应条件。
3. 可以开始尝试安装一个 Linux 发行版。
4. 记录一个遇到但暂时没有解决的问题，基础课可以用它讨论问题分类。

安装失败不影响参加基础课。macOS 候选人不需要完成本模块。

## 参加基础课前

请携带电脑，并确认：

- Git 已安装。
- GitHub 账号可以登录。
- 能找到一个终端。
- 知道自己创建的 `hello.txt` 保存在哪里。

不需要提前安装 uv、Rustup、Python 项目依赖、IDE 扩展或终端编辑器。
