# intro 与预备期交接

本文只规定约半小时软件组 intro 在结束前必须完成的后续交接，不设计 intro 对软件组工作和技术栈的具体介绍内容。

## intro 结束前必须说明

- 一周后将进行 2 小时计算机基础课。
- 预备内容预计耗时 60–90 分钟，不评分、不提交成果，已掌握者可以跳过。
- 候选人需要携带可用电脑参加基础课。
- 基础课前需要安装 Git，并准备可登录的 GitHub 账号。
- 候选人至少应当打开过终端、创建过纯文本文件，并尝试从终端定位该文件。
- Windows 候选人可以提前开始研究和配置 WSL2；基础课不依赖其配置成功。
- 基础课结束时会提供 Python/Rust 路线选择参照，但路线自由选择、无需登记，也不限制后续调整。

## 现场交接物

intro 最后展示统一入口的链接或二维码。入口至少包含：

- [一周预备内容](./preparation.md)
- [外部资源表](./resources.md)
- 基础课的时间、地点和携带设备要求
- 求助渠道和问题描述建议

## 不应传达的含义

- 预备任务不是第一次筛选。
- 安装失败不表示不适合软件组。
- 选择 Python 路线不代表能力较差。
- 选择 Rust 路线不代表必须已有 Rust 经验。
