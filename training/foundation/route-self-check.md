# Python/Rust 路线选择自测

本自测不提交、不计分、不登记答案，也不限制候选人之后调整路线。

请判断：

1. 我是否已经学习并理解变量、分支、循环和函数？
2. 面对已有的简单程序，我能否尝试阅读、运行并修改它？
3. 我能否使用任意语言，独立编写一个读取输入、做简单处理并输出结果的程序？
4. 遇到语法错误或运行错误时，我是否有过自行定位的经验？

## 选择参考

- 刚学完基础语法，希望通过已有程序开始项目实践：建议选择 Python 路线，在可运行的客户端—服务端起始仓库上扩展功能。
- 已能独立编写简单程序，并愿意学习新语言：可以选择 Rust 路线，即使从未学过 Rust。
- 尚未掌握基础语法：先补学再进入项目，仍可选择 Python；这不是参加基础课的前提。
- 如果仍然犹豫，可以先阅读两条路线的第一个任务，再自由选择。

选择 Python 不代表能力较差；选择 Rust 也不代表已经具备业务开发能力。两条路线观察的都是相对于自身起点的学习过程。
