# 00：操作系统概述与 WSL

建议时间：0–8 分钟。

## 学习目标

- 知道操作系统为程序和开发工具提供哪些基础能力。
- 认识 Windows、macOS、Linux、移动操作系统和嵌入式环境的主要类别。
- 对 Windows、WSL、WSL2 和 Linux 发行版形成第一层区分。

## 讲述结构

### 操作系统的职责

用一张分层图说明操作系统负责管理程序与进程、文件系统、内存、设备、用户权限和网络等公共资源。本课只建立全景，不讲内核或系统调用实现。

### 常见类别

- 桌面与服务器：Windows、macOS、Linux。
- 移动设备：Android、iOS。
- 嵌入式：裸机环境和实时操作系统，只作名称介绍。

强调分类会重叠，例如 Linux 可以运行在桌面、服务器或嵌入式设备上。

### WSL 简介

- WSL 让 Windows 用户使用 Linux 用户空间和工具。
- WSL2 使用 Linux 内核环境，但仍与 Windows 协作。
- 安装的 Linux 发行版、WSL 功能和一个终端窗口不是同一个对象。
- Windows 与 WSL 可以访问部分彼此文件，但各自的软件、PATH 和环境并不自动共享。

## 随讲随做

- 候选人确认自己的操作系统名称和大致版本。
- Windows 候选人观察自己是否已经安装 WSL；不在课堂排障。

## 常见误解

- “Linux 只用于服务器。”
- “WSL 只是一个终端皮肤。”
- “WSL、WSL2 和 Ubuntu 是同一个名字的三种写法。”

## 过渡

> 操作系统提供这些能力，而开发者最常见的文本操作入口之一是终端中的 shell。
