# 00：从计算机开发基础开始

建议时间：0–10 分钟。

## 学习目标

- 知道本课建立的是后续自学所需的共同模型，而不是教授一门语言。
- 理解课程从文件系统、路径、终端和 shell 开始，逐层进入项目开发工具。
- 知道哪些内容本课只做预览，哪些内容需要在正式项目中自学。

## 建议幻灯片

### 1. 今天不做什么

- 不教完 Python 或 Rust。
- 不带领完成正式项目。
- 不以现场配置是否成功评价候选人。

讲师说明：候选人暂时听不懂个别术语是正常现象，本课的目标是建立可以继续学习的地图。

### 2. 开场画面

直接展示一个终端窗口及其当前目录，提问：

> 这个窗口是什么？命令会在哪里执行？它能够看到和修改哪些文件？

不要求候选人立即回答。由此引出文件系统、当前目录、终端和 shell，课程从最基础的开发工作台开始，而不是从某个项目开始。

### 3. 课程地图

```text
文件系统、路径、终端和 shell
  → 源代码、程序和进程
  → 包、版本、依赖和项目环境
  → Git 与 GitHub
  → 测试和开发工具
  → 排障与自学
```

## 常见风险

- 不在开场重复 intro 中的软件组工作介绍。
- 不提前解释地图上的所有术语。
- 现场回答只用于建立问题，不评价谁答得多。

## 过渡

> 在讨论程序怎样运行之前，先要知道代码文件在哪里，以及命令究竟在哪个位置执行。
