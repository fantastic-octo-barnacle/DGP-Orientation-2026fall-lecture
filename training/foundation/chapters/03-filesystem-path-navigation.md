# 03：文件系统、路径与导航

建议时间：32–47 分钟。

## 学习目标

- 理解目录树、根位置、用户主目录和当前目录。
- 区分绝对路径与相对路径。
- 能够使用 shell 完成最基本的文件系统导航。
- 理解可以通过路径指定文件或启动程序。

## 讲述结构

### 文件系统层次

- 目录可以包含文件和其他目录。
- Windows 常以盘符组织路径。
- macOS、Linux 和 WSL 从根目录组织路径。
- 用户主目录与文件系统根不是同一个位置。

### 路径

- 绝对路径从固定根位置开始。
- 相对路径以当前目录为起点。
- `.` 表示当前目录，`..` 表示上级目录。
- Windows 与 Unix 风格的路径分隔符不同。
- 路径含有空格时，shell 需要知道哪些字符共同组成一个参数。

### 导航与通过路径操作

- 查看当前目录。
- 查看目录内容。
- 切换到子目录或上级目录。
- 使用相对路径和绝对路径查看同一个文件。
- 使用明确路径运行一个程序或脚本。

## 随讲随做

每讲完一个概念立即完成一个小操作：

1. 查看当前目录。
2. 查看其中的文件和目录。
3. 进入预备期文件所在目录。
4. 返回上一级目录。
5. 用相对路径查看 `hello.txt`。
6. 用绝对路径查看同一文件。

不一次性发放长命令清单。

## 演示：文件存在但找不到

讲师在错误当前目录运行读取相对路径的程序，展示找不到文件；切换当前目录或使用正确路径后重新运行。强调文件和源码都没有变化，改变的是路径解析起点。

## 常见误解

- “终端默认位于文件管理器当前打开的位置。”
- “文件名就是完整路径。”
- “相对路径在任何位置都指向同一文件。”
- “在路径中增加引号会改变文件名。”

## 过渡

> 路径可以明确指出一个程序在哪里；但平时只输入程序名称时，shell 还需要 PATH 等环境信息来找到它。
