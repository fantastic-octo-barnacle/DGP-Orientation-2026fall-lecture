# 01：文件、路径、终端与进程

建议时间：10–25 分钟。

## 学习目标

- 理解源代码是存放在文件中的纯文本。
- 区分文件、目录、路径和当前目录。
- 区分编辑器、文件管理器、终端和 shell。
- 初步理解程序与正在运行的进程不是同一个对象。

## 建议幻灯片

### 1. 代码首先是文件

并排展示 `main.py`、`main.rs` 和 `README.md` 的文本内容。强调扩展名和内容约定不同，但它们都可以由普通文本工具查看。

不把 IDE 产生的颜色、补全和按钮解释成源代码的一部分。

### 2. 文件、目录和路径

使用一棵很小的目录树：

```text
foundation/
├── README.md
├── message.txt
├── python-demo/
└── rust-demo/
```

依次引入：

- 文件名。
- 目录。
- 绝对路径与相对路径。
- 当前目录是相对路径的解释起点。

### 3. 四种工具

| 工具 | 主要职责 |
|---|---|
| 编辑器 | 修改文件内容 |
| 文件管理器 | 浏览和操作文件系统 |
| 终端 | 提供文本交互界面 |
| shell | 读取命令并启动程序 |

不深入讲终端模拟器、shell 实现或命令语法差异。

### 4. 程序与进程

- 程序文件可以长期保存在磁盘上。
- 运行程序时，操作系统创建进程。
- 同一个程序可以同时产生多个进程。
- 关闭编辑器不一定会关闭已经启动的程序。

## 演示：文件存在但找不到

1. 在文件管理器中展示 `message.txt`。
2. 在错误的当前目录运行演示程序。
3. 展示找不到文件的错误。
4. 查看当前目录并切换到正确位置。
5. 重新运行成功。

结论：文件没有移动，代码也没有变化；变化的是运行程序时的当前目录。

## 课堂活动

候选人打开终端：

1. 判断当前目录。
2. 尝试定位预备期创建的 `hello.txt`。

幻灯片按 PowerShell 与 macOS/Linux 两列给出课堂所需的少量命令。评价操作目标，不要求背相同命令。

## 常见误解

- “打开终端后默认就在项目目录。”
- “文件管理器能看到文件，程序就一定能找到。”
- “编辑器中的运行按钮是源代码的一部分。”
- “终端、shell 和操作系统是同一个东西。”

## 过渡

> 找到源代码以后，操作系统仍然不一定知道怎样直接运行它；还需要解释器、编译器或已经生成的可执行程序。
