# 01：终端、shell、命令与命令行

建议时间：8–18 分钟。

## 学习目标

- 区分终端、shell、命令行和命令。
- 知道 shell 会维护当前目录和环境，并启动其他程序。
- 理解图形界面和命令行是不同交互方式，不是能力高低的标志。

## 讲述结构

```text
终端：提供文本交互界面
  ↓
shell：读取并解释输入
  ↓
内建命令改变 shell 状态，其他命令启动程序
```

- 命令行是用户以文本方式输入命令的交互形式。
- 有些命令由 shell 自己处理，例如改变当前目录。
- 有些命令对应磁盘上的可执行程序。
- shell 本身也是程序，不等同于操作系统。

## 随讲随做

1. 打开终端。
2. 执行一个最简单的文本输出命令。
3. 打开第二个终端窗口，观察它是另一个交互会话。
4. 暂时只观察提示符，不解释所有符号。

课堂材料分别列出 PowerShell 与 macOS/Linux 所需的少量命令，不要求候选人背统一写法。

## 不展开

- shell 脚本。
- 管道和重定向。
- PowerShell profile 或 shell 启动文件。
- 各种 shell 的历史和语法比较。

## 过渡

> shell 要操作文件，首先需要理解文件有哪些形式，以及操作系统怎样组织它们。
