# 培训材料

本目录覆盖半小时 intro 与后续内容的交接、一周预备期，以及 2 小时计算机基础课。正式项目指引和最终面试不在本目录中设计。

2 小时课程以“计算机开发基础”为主题，从操作系统、命令行、shell、文件与文件系统开始，逐步进入程序、项目环境和工程工具。[基础课 demo](../demos/foundation/README.md) 保存在本仓库中，在第二小时按需穿插使用；它不作为开场或全课的主叙事，也不同于正式项目的 Demo C。

## 时间线

1. 约半小时软件组 intro。
2. 约一周预备学习与环境准备。
3. 2 小时计算机基础课。
4. 候选人自由选择 Python 或 Rust 路线，进入约一个月的正式项目。
