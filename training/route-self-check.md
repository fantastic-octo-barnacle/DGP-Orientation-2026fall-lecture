# Python/Rust 路线选择自测

本自测不提交、不计分、不登记答案，也不限制候选人之后调整路线。

请判断：

1. 我能否使用任意语言独立创建并运行一个程序？
2. 我是否理解变量、分支、循环和函数？
3. 我能否编写一个读取输入、做简单处理并输出结果的程序？
4. 遇到语法错误或运行错误时，我是否有过自行定位的经验？

## 选择参考

- 多数回答“不确定”或“不能”：建议优先选择 Python 起点路线。
- 多数回答“能”：可以选择 Rust 起点路线，即使从未学过 Rust。
- 如果仍然犹豫，可以先阅读两条路线的第一个任务，再自由选择。

选择 Python 不代表能力较差；选择 Rust 也不代表已经具备业务开发能力。两条路线观察的都是相对于自身起点的学习过程。
