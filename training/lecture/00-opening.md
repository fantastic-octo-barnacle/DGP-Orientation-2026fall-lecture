# 00：开场与课程地图

建议时间：0–10 分钟。

## 学习目标

- 知道本课建立的是后续自学所需的共同模型，而不是教授一门语言。
- 理解课程围绕“如何让项目在另一台电脑上运行”展开。
- 知道哪些内容本课只做预览，哪些内容需要在正式项目中自学。

## 建议幻灯片

### 1. 今天不做什么

- 不教完 Python 或 Rust。
- 不带领完成正式项目。
- 不以现场配置是否成功评价候选人。

讲师说明：候选人暂时听不懂个别术语是正常现象，本课的目标是建立可以继续学习的地图。

### 2. 开场问题

展示 `foundation-demo` 的 GitHub 文件页面，提问：

> 将这些文件下载到另一台电脑，为什么不一定能直接运行？

接受“缺软件”“版本不同”“缺少库”“路径不同”等简短回答，暂不逐项纠正。将回答记录在一侧，课程结尾再返回。

### 3. 课程地图

```text
源码与文件
  → 解释器或编译器
  → 包、版本、依赖和环境
  → Git 与 GitHub
  → 测试和开发工具
  → 排障与自学
```

## 常见风险

- 不在开场重复 intro 中的软件组工作介绍。
- 不提前解释地图上的所有术语。
- 现场回答只用于建立问题，不评价谁答得多。

## 过渡

> 在讨论程序怎样运行之前，先要知道代码文件在哪里，以及命令究竟在哪个位置执行。
