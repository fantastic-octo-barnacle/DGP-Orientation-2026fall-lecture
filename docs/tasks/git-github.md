# Git 与 GitHub 基础任务

本任务适用于 Python 与 Rust 两条路线。任务只使用 Markdown 等纯文本文档，不要求编写程序，也不要求提交练习成果。

## 学习目标

- 理解工作目录、暂存区、本地仓库和远程仓库的区别。
- 理解 Git 与 GitHub 的区别。
- 理解修改、提交、推送、拉取和克隆之间的关系。
- 理解 `.gitignore` 的用途及其对已跟踪文件的限制。
- 理解源代码和普通文档都是可以由版本控制跟踪的纯文本。

## 任务

1. 创建一个文档目录，其中包含 `README.md`、`learning-map.md` 和 `notes.md`。
2. 建立 Git 仓库，分几次修改文档并留下有意义的版本历史。
3. 在 GitHub 创建个人仓库并同步本地内容。
4. 在另一个目录重新取得仓库，确认文件和版本历史存在。
5. 分别从本地和 GitHub 修改文档，完成双向同步。
6. 创建一个不应进入版本历史的临时笔记目录，并使用 `.gitignore` 排除。
7. 已掌握基础内容者可以练习分支、合并和一次可控的文本冲突。

## 自检

- 能否判断一个修改目前只在工作目录、已经提交，还是已经同步到 GitHub？
- 能否解释 commit 与 push 为什么不是同一个操作？
- 能否解释 clone 得到了哪些内容？
- 能否解释为什么加入 `.gitignore` 后，某个此前提交过的文件仍可能被跟踪？

## 范围外内容

不要求掌握 rebase、cherry-pick、reflog、submodule、复杂 reset 或冷门参数。
