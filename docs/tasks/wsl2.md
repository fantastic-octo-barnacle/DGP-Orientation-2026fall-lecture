# WSL2 基础任务

本任务适用于使用 Windows 且设备条件允许的候选人。macOS 候选人不设置对等任务。任务不要求提交截图、日志或仓库。

## 学习目标

- 区分 Windows、WSL、WSL2、Linux 内核和 Linux 发行版。
- 理解 Windows 与 WSL 拥有各自的软件、路径和运行环境。
- 能够完成基本的 Linux 文件与目录操作。
- 能够在 Windows 与 WSL 文件系统之间定位普通文件。

## 任务

1. 根据官方资料安装 WSL2 和一个 Linux 发行版。
2. 启动发行版，判断当前终端属于 Windows 还是 Linux。
3. 查看当前目录、用户目录和基本系统信息。
4. 浏览 Linux 文件系统，并创建、复制和移动普通目录或文件。
5. 在 Windows 中使用普通文本编辑器创建一个文件，再从 WSL 中找到并读取它。
6. 在 WSL 中创建普通文件，再从 Windows 一侧找到它。
7. 分别判断一个工具在 Windows 和 WSL 中是否安装。
8. 正常退出并关闭 WSL 环境。

## 自检

- 为什么 Windows 已经安装的软件在 WSL 中可能无法直接使用？
- Windows 路径与 Linux 路径有什么区别？
- WSL、WSL2 和安装的 Linux 发行版分别是什么？
- 关闭终端窗口与关闭 WSL 环境是否一定相同？

## 边界

不要求在 WSL 中完成后续编程项目，也不要求使用 Vim、配置 IDE、编写 shell 脚本、使用 Docker、管理 systemd 服务或学习复杂权限规则。

已配置 WSL2 的候选人不必重装。存在客观设备限制时，不把未完成配置作为淘汰红线。
