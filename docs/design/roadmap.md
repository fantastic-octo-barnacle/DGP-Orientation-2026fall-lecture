# 详细设计路线图

培训与考核的总体框架已经确认。后续按以下顺序详细设计并存档，每一阶段完成后再进入下一阶段。

## 1. 培训

详细设计：

- 约半小时软件组 intro。
- intro 与基础课之间约一周的预备学习和环境准备。
- 2 小时计算机基础课的学习目标、讲义结构、演示和课堂活动。
- intro、预备内容、基础课与后续正式项目之间的知识边界。

## 2. 正式项目

在培训内容稳定后，完成：

- 共同 Git、GitHub 和 WSL2 任务指引。
- Python 环境 Demo 与正式编程项目 spec。
- Rust 客户端—服务端项目 spec、三个独立 Cargo 项目的起始仓库设计。
- 示例数据、参考程序、验收场景和候选人版项目文档。

## 3. 最终面试

在培训和项目内容稳定后，重新设计：

- 正式面试流程。
- 固定题树及升级、提示、降级分支。
- 基本命令行实操。
- 项目仓库预审方法。
- 评委记录表和校准流程。

现有面试题库仅为早期草案，不作为最终题目。
