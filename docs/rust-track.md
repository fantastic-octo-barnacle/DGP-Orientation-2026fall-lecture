# Rust 起点路线

Rust 路线面向已经掌握任意语言基本编程概念、但不一定接触过 Rust 的候选人。项目通过本地客户端与服务端通信，观察语言迁移、环境搭建、协议理解、错误处理、调试和异步学习能力。

项目只在本机通信，不涉及硬件、嵌入式部署、GUI、数据库、鉴权、加密或公网服务，也不强制映射视觉、导航等专业方向。

## 共同基础

Rust 候选人同样需要学习 Git、GitHub 和适用 Windows 候选人的 WSL2 配置。具体目标见[共同基础任务](./common-foundations.md)。后续 Rust 项目不要求在 WSL2 中完成。

## 参考程序

出题方使用 Rust 编写一个同时支持客户端和服务端模式的命令行程序：

```text
rm-recruit-reference server ...
rm-recruit-reference client ...
```

参考程序用于替换通信的一端，帮助候选人验证自己的实现并判断问题位于客户端还是服务端。协议完整公开，不把参考程序设计为逆向题。

参考程序通过相应平台的原生构建环境或 CI 构建矩阵发布，目标至少考虑 Windows、Linux、macOS Apple Silicon，并根据实际设备情况考虑 macOS Intel。发布文件附版本和校验信息。

项目指南提示 macOS 可能阻止直接运行下载的程序，要求候选人研究原因并安全解决，但不直接提供放行答案。

## 通信协议

协议采用每行一个 JSON 消息的形式。核心动作保持简单：

- `ping`
- `echo`
- `delay`

`delay` 用于观察慢请求是否阻塞其他客户端，不用于增加业务复杂度。协议的精确错误代码、长度限制和延迟上限将在具体任务书中确定。

请求形式为：

```json
{"id":1,"action":"ping"}
{"id":2,"action":"echo","data":"hello"}
{"id":3,"action":"delay","milliseconds":1000,"data":"hello"}
```

成功响应包含对应 `id`、`ok: true` 和结果；错误响应包含可用的请求 `id`、`ok: false`、错误代码与说明。

协议边界如下：

- 使用 UTF-8 编码，每行一个完整 JSON 消息。
- 每个请求产生一个响应。
- 同一连接内依次处理请求，不要求请求多路复用。
- 异步并发只要求发生在不同客户端连接之间。
- 非法请求尽量返回错误并保留连接。
- 单行长度和 `delay` 时长设置公开的合理上限。
- 核心异步验收场景是：一个连接正在等待 `delay` 时，另一个连接仍能立即获得 `ping` 响应。

## 项目层级

### 0. Rust 与 Cargo

- 创建个人 GitHub 仓库和 Cargo 项目。
- 运行最小程序。
- 理解源码、依赖、构建产物和 `.gitignore`。

### 1. 最小客户端

- 连接参考服务端。
- 发送一个固定请求。
- 接收并显示响应。

### 2. 可用客户端

- 从命令行构造多种请求。
- 处理连接失败和错误响应。
- 支持连续交互。

### 3. 同步服务端

- 接收一个客户端。
- 实现公开协议中的核心动作。
- 与自己的客户端和参考客户端兼容。

### 4. 健壮服务端

- 处理连续请求、非法 JSON、未知动作和客户端断开。
- 增加必要的配置、日志和测试。

### 5. Tokio 服务端

- 使用 Tokio 同时处理多个客户端。
- 一个客户端的 `delay` 请求不阻塞其他连接。

### 6. 异步完善

- 超时。
- 任务清理。
- 优雅退出。
- 并发客户端测试。

### 扩展

- 使用 CI 自动执行格式检查、Clippy 和测试。

## 依赖与工具

固定运行依赖包括：

- Serde、Serde JSON。
- Tokio。
- Clap，用于较高层级的命令行参数。

开发工具包括：

- `cargo fmt`
- `cargo clippy`
- `cargo test`

错误处理库不固定要求。候选人可以使用标准库、`anyhow` 或 `thiserror`，但需要理解自己的选择。可以推荐 rust-analyzer，但不要求配置特定 IDE。

## 仓库与评价

仓库需要包含源码、测试、Cargo 项目文件、锁文件、恰当的 `.gitignore`、README 和自然的提交历史。可以使用简短的 `PROGRESS.md` 记录三个轻量检查点，不要求日报。

完成 Tokio 层级不是机械的录取门槛。项目未完成但学习进展、问题分析和理解程度突出的候选人仍可录取。
