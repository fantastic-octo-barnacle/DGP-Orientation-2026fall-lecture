# Python 项目环境 Demo

本组 Demo 用于观察解释器、工作目录、依赖隔离和项目复现。代码均由出题方提供，不要求候选人提交操作成果。

## Demo A：解释器与项目

程序显示：

- Python 版本。
- `sys.executable`。
- 当前工作目录。

候选人从不同目录运行程序，观察源码位置、解释器和工作目录并不是同一概念。

## Demo B：独立环境

提供两个代码完整的小项目：

- B1 使用一个当前受支持的 Python 版本和一个简单第三方依赖。
- B2 使用另一个当前受支持的 Python 版本和另一项简单依赖。

两个程序都显示当前 Python 版本、解释器路径、依赖版本和工作目录。候选人分别恢复并运行环境，观察两个项目拥有各自的解释器选择、`.venv` 和依赖集合。

具体 Python 版本和第三方依赖每届更新，不在长期方案中写死。Demo 不依赖第三方包的历史不兼容 API 来刻意制造冲突。

## Demo C：完整工具链仓库

候选人从 GitHub clone 一个没有 `.venv`、但包含完整 uv、pytest、Ruff 和 Pyright 配置的示例项目，恢复环境并观察各类工具。具体设计见 [Python Demo C](./python-demo-c.md)。
