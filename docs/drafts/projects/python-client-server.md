# Python 本地客户端—服务端项目草案

本项目要求候选人在可运行的 Python 客户端—服务端起始仓库上扩展功能：先为客户端接入文本统计，再在两端实现数值统计和内存键值存取。

本文件依据[Python 项目总体设计](../../design/python-track.md)细化任务书。层级和分工已经确认；下列具体消息字段、边界规则与验收示例是待实现验证的草案，不是已发布 spec。

## 提供与实现的边界

| 部分 | 出题方提供 | 候选人完成 |
|---|---|---|
| 环境与通信 | uv、检查工具、同步通信、JSON 分帧、请求分发和错误响应 | 恢复环境、理解调用关系、保留既有行为 |
| `ping/echo` | 完整两端及测试 | 运行、阅读和回归验证 |
| `text_stats` | 服务端实现及测试 | 客户端入口、请求、显示及客户端测试 |
| `number_stats` | 行为约定和少量正常自查用例 | 两端实现、校验与测试 |
| `set/get/delete/list` | 行为约定和少量正常自查用例 | 两端实现、状态与测试 |

客户端为文字菜单，支持连续操作。手写 JSON 可用于调试，不能替代新增功能的正常客户端入口。协议允许换行文本，客户端具体输入方式在起始仓库实现时确定。

## 消息示例

消息使用 UTF-8 编码，每行一个完整 JSON 消息。请求中的 `id` 用于对应响应，`action` 指定操作，其余字段提供操作参数。服务端顺序处理同一连接内的请求，每个请求对应一个响应。

响应携带对应的 `id`；成功时含 `ok: true` 和 `result`，失败时含 `ok: false` 和错误代码、说明。字符串内的换行用 JSON 转义表示，不能被误作消息边界。以下示例中，每个请求后紧跟对应响应：

```json
{"id":1,"action":"text_stats","text":"hi\nRM"}
{"id":1,"ok":true,"result":{"characters":5,"lines":2}}
{"id":2,"action":"number_stats","numbers":[1,2,3]}
{"id":2,"ok":true,"result":{"count":3,"min":1,"max":3,"mean":2}}
{"id":3,"action":"set","key":"name","value":"robot"}
{"id":3,"ok":true,"result":{}}
{"id":4,"action":"get","key":"name"}
{"id":4,"ok":true,"result":{"value":"robot"}}
```

## 拟定业务规则

### 基础层：文本统计

- `text` 必须是字符串；不自动去除空白。
- 字符数按 Python 字符串长度计算，包含空白和换行，不按 UTF-8 字节数计算。
- 拟将空字符串行数定义为 0；其他文本按换行符 `\n` 分隔的段数计数，因此末尾换行增加一个空行。
- 示例：空文本 → 0 字符、0 行；`abc` → 3 字符、1 行；`a\n` → 2 字符、2 行。
- 这些规则由提供的服务端实现。候选人须正确传输和显示结果，不在客户端另算一份结果来绕过服务端。

### 标准层：数值统计

- `numbers` 为非空列表，元素为有限整数或浮点数，布尔值不作为数值接受。
- 不将数值字符串静默转换为协议数值；客户端将用户输入解析为数值的行为应有明确提示。
- 空列表、错误类型、缺少参数和非有限数值返回参数错误。
- 测试覆盖单元素、负数、小数、重复值和非法元素；平均值测试使用合理浮点容差。
- 溢出或无法表示的计算结果应返回可理解错误；发布前应确定公开的数值范围和列表长度限制。

### 进阶层：键值存取

- `key` 拟定为非空字符串，`value` 为字符串；空字符串值允许保存。
- `set` 写入或覆盖；`get` 返回当前值；`delete` 删除；`list` 返回现存键列表。
- `get/delete` 操作不存在的键时返回明确错误；空状态下 `list` 返回空列表，拟按键排序保证输出稳定。
- 数据属于服务端进程，跨请求、跨客户端重新连接保留，服务端重启后清空。
- 不要求同时服务多个客户端。顺序断开并重新连接即可验证状态归属。

## 验证安排

起始框架全部测试通过，不故意埋 bug。新增功能提供少量正常场景自查用例，不交付完整异常与边界测试答案。

公开验收场景包括：

1. 起始版本完成 `ping/echo`；候选人能够说明完整调用路径。
2. 客户端发送文本并显示服务端统计；覆盖空文本和换行文本。
3. 数值统计正常工作；非法请求得到错误，后续合法请求仍可执行。
4. 依次执行写入、读取、覆盖、列举、删除和缺失键读取，核对状态变化。
5. 客户端重连后值仍存在，服务端重启后为空。
6. 扩展后原有 `ping/echo/text_stats` 不回归。

任务书说明应验证哪些行为，由候选人自行补充测试。基础层需要验证客户端请求构造、响应显示和正常操作入口，不以已有服务端测试代替。
