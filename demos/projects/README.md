# 正式项目配套材料

本目录预留给正式项目 spec 所需的示例项目和参考实现，例如 Python 环境 Demo C、Rust 参考程序及其构建资源。

具体内容将在培训材料稳定后，按照 [`docs/design/roadmap.md`](../../docs/design/roadmap.md) 设计。候选人版材料应与内部面试题、评价说明和标准答案保持隔离。

Rust 配套材料包括[起始仓库](../../docs/drafts/projects/rust-starter.md)和[独立参考程序](../../docs/drafts/projects/rust-reference-program.md)。起始仓库公开源码，包含同步客户端、同步服务端、异步服务端三个独立 Cargo 项目，不使用 workspace；参考程序考核期间以可执行文件提供。当前仅有设计，尚未实现或发布。
